# EUCATRINE_WP5_6

This repository contains code developed for the [EU-CATRINE project](https://www.catrine-project.eu/). This README gives a brief overview of its main directories.

- **`Code - IFS`** — Code for processing raw IFS data into datasets for analysis and comparison with other models and observations.
- **`Code - Testbed`** — Contains two files: the testbed, which includes time series, vertical profiles, and statistical analyses (see the technical report), and a process-based scorecard demonstrating the proof of concept.
- **`code-utils`** — Utility functions for common calculations.
- **`Extraction scripts`** — Scripts for retrieving model-level and surface-level IFS data from the ECMWF MARS archive for experiments. For example, `itr2`, which is equivalent to `ia61` and uses a horizontal resolution of 28 km.
- **`Results`** — Subdirectories containing figures from the testbed and scorecard.

The code in this repository may change as the author’s work continues on EU-CATRINE, their PhD, and/or related projects. For the latest information, please contact the author (Vincent de Feiter).
